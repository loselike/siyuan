# 思远物流用户手册（初版）

版本日期：2026-06-06

## 1. 系统定位

思远物流是一套面向跨境物流业务的 AI TMS / OMS 系统。当前版本覆盖员工端和客户门户的第一版闭环，重点支持快递、小包、专线三类业务下的运单履约、收货打单、渠道排货、轨迹监控、问题件、报价查价、财务结算、统计报表、基础资料和系统设置。

当前系统以“可演示、可验证、可扩展”为目标：核心业务动作已经具备页面和接口闭环；承运商 API、真实打印机、电子秤、PDA、微信入口等高级能力先预留接口和业务位置，后续逐步接入。

## 2. 角色与权限边界

系统按角色隔离菜单、页面、按钮和数据范围。系统页面不展示任何账号密码。

| 角色 | 主要定位 | 可见能力 |
| --- | --- | --- |
| 系统管理员 | 平台最高权限 | 全部员工端菜单、权限配置、系统设置、财务核销、基础资料维护 |
| 客服 | 客户服务与问题处理 | 运单查询、问题件处理、轨迹跟进、报价查询、基础资料读取 |
| 操作 | 仓库与履约作业 | 运单履约、收货打单、渠道排货、轨迹监控、问题件、基础资料读取 |
| 财务 | 账务与对账 | 财务结算、报价查价、统计报表、基础资料读取、运单读取 |
| 客户 | 客户自助门户 | 本人运单、本人问题件、本人费用、对账单、账户余额 |

权限原则：

- 系统设置、员工账号管理、角色权限分配仅系统管理员可见。
- 财务核销仅系统管理员和财务可操作。
- 操作角色不应进入系统设置和财务核销页面。
- 客户登录后进入客户门户，不显示员工端菜单。
- AI 接口要求登录后调用，并遵守当前登录角色的数据边界。

## 3. 顶部通用功能

### 3.1 业务类型切换

顶部提供“快递 / 小包 / 专线”三类业务切换。

- 快递：适合 DHL、FedEx、UPS 等商业快件，关注转单号、偏远费、燃油、上网和签收。
- 小包：适合轻小件、挂号和平邮，关注批量预报、邮袋交接、克重段、上网时效。
- 专线：适合专线、FBA、海外仓和卡派，关注装板排舱、清关资料、尾程转单。

切换后，首页 KPI、状态池、表格数据和 AI 建议会按业务类型聚合。

### 3.2 全局搜索

顶部搜索框用于按客户、客户单号、系统单号、转单号、国家和渠道快速筛选运单。适合客服查件、操作定位待处理票、财务核对费用来源。

### 3.3 权限视图

权限视图用于提醒当前账号处于什么权限范围。后续可扩展成“当前角色可见菜单、可用按钮、数据范围”的只读说明页。

### 3.4 AI 工作流

点击“AI 工作流”后，系统会基于当前业务类型、运单数量、风险数量调用 AI 助手，输出运营建议。当前已接入硅基流动接口；如果外部接口异常，系统会返回本地兜底建议，避免页面无响应。

## 4. 运营工作台

运营工作台是员工端首页，用于快速掌握当天跨境物流全局情况。

核心意义：

- 将快递、小包、专线数据按业务类型汇总。
- 用状态池展示草稿、已预报、待收货、待排货、待发货、待上网、待签收、退货、异常等数量。
- 用运单池表格承载日常筛选、批量操作和单票跟进。
- 用 AI 队列识别轨迹超时、缺转单号、问题件、偏远费等风险。

常见使用：

- 管理员查看总体运营压力。
- 客服按客户单号或转单号查件。
- 操作筛选待收货、待排货、待发货票据。
- 财务从运单维度追溯费用来源。

## 5. 运单履约

运单履约是核心业务页面，用于管理运单从预报到签收的完整生命周期。

核心功能：

- 预报：客户或员工录入基础运单资料。
- 导入运单：批量导入客户单号、国家、重量、渠道等信息。
- 收货：仓库确认实际收到包裹。
- 打单：生成或模拟生成面单、转单号。
- 排货：分配渠道、代理、承运商。
- 发货：确认出库并进入待上网阶段。
- 获取转单号：为缺少转单号的运单补齐承运商单号。
- 轨迹：维护客户可见轨迹和内部跟进状态。
- 退货 / 滞留：标记退货、滞留、问题件等异常状态。

页面意义：

- 让操作人员在一个页面看到每票货的“当前状态、下一步动作、AI 建议”。
- 降低漏处理、跳状态、错发货风险。
- 支持批量排货、批量获取转单号、批量添加轨迹等操作。

当前边界：

- 第一版动作以系统数据闭环为主，不直接触发真实承运商发货。
- 状态流转会校验合法性，避免从草稿直接跳到签收等错误操作。

## 6. 收货打单

收货打单中心面向仓库作业。

核心功能：

- 扫描收货：按系统单号或客户单号确认入库。
- 批量收货：对同批次货物批量确认。
- 打单录入：创建或关联面单信息。
- 重量复核：复核实重、材积重和计费重。
- 包裹明细：维护长宽高、件数和包裹类型。
- 面单预览：查看模拟面单结果。
- 异常入库：标记重量异常、重复扫描、资料缺失等问题。

业务意义：

- 把客户预报和仓库实物收货对齐。
- 发现重量差异、重复扫描、缺资料等风险。
- 为后续排货、报价、应收应付生成提供可信基础数据。

AI 能力：

- 识别重量异常。
- 提醒重复扫描。
- 根据运单资料补全打单信息建议。

## 7. 渠道排货

渠道排货中心用于决定每票货走哪个渠道、代理和承运商。

核心功能：

- 规则排货：按国家、重量、时效、渠道规则给出排货建议。
- 手动排货：人工选择渠道、代理、承运商。
- 批量排货：对多个待排货运单统一分配渠道。
- 代理 / 承运商选择：维护实际执行方。
- 获取转单号：模拟或后续通过 API 获取承运商转单号。
- 填写转单号：手工补录承运商单号。
- 排货日志：记录排货变化和操作原因。

业务意义：

- 控制成本、时效和服务稳定性。
- 避免缺转单号导致无法跟踪。
- 为财务核算代理成本和客户报价提供依据。

AI 能力：

- 推荐最优渠道。
- 解释成本倒挂原因。
- 给出批量排货风险提示。

## 8. 轨迹监控

轨迹监控中心用于跟踪运单上网、运输和签收。

核心功能：

- 轨迹列表：查看每票运单最新轨迹。
- 手工添加轨迹：录入客户可见或内部轨迹。
- 未上网监控：识别发货后长期未上网的票。
- 未更新队列：识别多日无更新的票。
- 标记上网：将运单推进到待签收阶段。
- 标记签收：确认妥投。
- 生成客户说明：为客服沟通生成说明草稿。

业务意义：

- 将“客户问件”变成系统化跟踪。
- 及时识别承运商接口失败、上网延迟、派送异常。
- 减少客服人工逐票判断成本。

AI 能力：

- 解释轨迹超时原因。
- 诊断接口失败。
- 生成客户沟通话术。

## 9. 问题件中心

问题件中心用于处理异常、投诉和需要客户确认的运单。

核心功能：

- 新建问题：员工或客户发起问题件。
- 回复 / 查看：员工与客户围绕问题件沟通。
- 客户回复模拟：验证客户侧可见回复流程。
- 关闭问题：处理完成后关闭。
- 上传附件：为后续上传照片、单证、截图预留位置。
- 客户可见状态：控制哪些内容客户可见。
- 关联运单：问题件必须能追溯到具体运单。
- SLA 跟进：识别长时间未处理的问题件。

业务意义：

- 把异常沟通结构化，避免只在聊天软件里流转。
- 区分内部备注和客户可见内容。
- 为客服、操作、财务协作提供统一上下文。

AI 能力：

- 归类问题原因。
- 生成回复建议。
- 提醒 SLA 超时风险。

## 10. 报价查价

报价查价中心用于计算客户报价、代理成本和渠道费用。

核心功能：

- 客户报价：按客户、渠道、国家、重量计算应收。
- 代理成本价：记录代理或承运商成本。
- 渠道报价：按渠道维护报价规则。
- 国家分区：不同国家或邮编对应不同分区。
- 重量段规则：按重量段计算费用。
- 燃油附加费：按渠道燃油比例计算。
- 偏远附加费：按邮编、国家或承运商规则加收。
- 价格试算：输入国家、重量、渠道后快速得到报价。

业务意义：

- 让客服和销售快速答复客户。
- 让财务核对利润和成本倒挂。
- 为运单生成应收费用提供标准依据。

AI 能力：

- 自然语言查价。
- 解释客户价和代理成本差异。
- 推荐更优渠道或报价方案。

## 11. 财务结算

财务结算中心用于处理应收、应付、对账、收付款、核销和余额流水。

核心功能：

- 应收费用：客户应支付费用，如基础运费、燃油费、附加费。
- 应付费用：应付代理、承运商或供应商成本。
- 客户对账：生成客户对账单草稿。
- 代理对账：与代理或承运商核对成本。
- 收款登记：记录客户付款。
- 付款登记：记录对代理或供应商付款。
- 核销：将收付款与费用匹配。
- 余额流水：展示客户账户余额变化。

业务意义：

- 将运单、报价和账务连接起来。
- 保证应收、应付、利润和余额可追溯。
- 控制欠费、漏核销和成本异常。

AI 能力：

- 解释费用差异。
- 提醒欠费和授信风险。
- 生成对账单摘要。

权限边界：

- 财务核销仅财务和管理员可用。
- 客服、操作不能执行财务核销。
- 客户只能查看本人费用、对账单和账户余额。

## 12. 统计报表

统计报表中心用于运营和管理层查看业务表现。

核心功能：

- 运单报表：按时间、客户、渠道、国家统计运单。
- 收货统计：统计仓库收货数量、异常数量和处理效率。
- 发货统计：统计出库、渠道和发货批次。
- 应收应付分析：对比客户应收和代理应付。
- 利润分析：评估业务毛利和异常成本。
- 客户报表：按客户维度汇总。
- 代理报表：按代理或承运商维度汇总。
- 日报生成：生成运营日报。

业务意义：

- 支持日常复盘和管理决策。
- 发现利润波动、时效异常、渠道异常。
- 为客户和代理结算提供汇总依据。

AI 能力：

- 生成运营日报。
- 解释利润波动。
- 识别收发货异常趋势。

## 13. 基础资料

基础资料中心维护系统运行所需的主数据。

核心功能：

- 客户创建：维护客户档案、客户代码和启停状态。
- 客户端账号创建：为客户创建门户账号。
- 客户联系人：维护联系人、电话、邮箱。
- 代理创建：维护代理档案。
- 代理账号创建：为代理协同预留。
- 承运商：维护 DHL、UPS、FedEx、USPS 等承运商。
- 渠道：维护渠道和承运商绑定关系。
- 费用名称：维护基础运费、燃油费、偏远费等费用字典。
- 汇率：维护 USD、EUR 等币种汇率。
- 触发器：为自动计费、自动提醒、自动状态流转预留。

业务意义：

- 保证运单、报价、财务使用统一的数据标准。
- 所有资料默认软删除或启停，不建议物理删除。
- 后续承运商 API、代理 API、自动报价都依赖基础资料质量。

AI 能力：

- 识别客户资料缺失。
- 检查渠道配置冲突。
- 生成资料维护建议。

## 14. 系统设置

系统设置中心仅系统管理员使用，用于管理平台级配置。

核心功能：

- 公司资料：维护公司基础信息。
- 模板：维护面单、通知、对账单等模板。
- 通知：配置客户通知和内部提醒。
- 轨迹规则：配置未上网、未更新、签收等规则。
- 状态字典：维护运单状态含义。
- 员工账号管理：查看角色账号和数据范围，不展示密码。
- 角色权限分配：配置角色可用权限。
- 客户端角色权限：为客户管理员、客户操作员、客户财务等角色预留。
- 审计日志：记录高风险操作。
- AI 接口安全：检查 AI 调用是否受登录态和权限控制。

业务意义：

- 统一控制系统能力边界。
- 防止普通员工越权访问财务或系统配置。
- 为后续真正的角色、菜单、按钮、数据范围 CRUD 打基础。

权限边界：

- 只有系统管理员可进入。
- 权限变更必须写入审计日志。
- 页面不展示账号密码。

## 15. 客户门户

客户门户是客户登录后的自助页面。

核心功能：

- 预报运单：客户创建待收货运单。
- 我的运单：查看本人或所属客户公司的运单。
- 问题件：查看和回复本人相关问题件。
- 价格查询：查询可用报价。
- 偏远 / 邮编 / 黑名单查询：为后续规则查询预留。
- 对账单：查看客户对账单。
- 费用明细：查看本人费用。
- 账户余额：查看账户余额和流水。
- 个人中心：维护客户侧基础信息。

业务意义：

- 减少客服重复录单和查件压力。
- 让客户自助查看轨迹、费用和问题件。
- 将客户预报、问题沟通和财务对账纳入同一个系统。

权限边界：

- 客户不能访问员工端菜单。
- 客户不能访问员工基础资料接口。
- 客户只能看到本人或所属客户公司的数据。

## 16. AI 功能说明

当前 AI 能力统一通过系统内 AI 助手调用。页面中的“AI 工作流”“AI 批量处理”“AI 辅助处理”“AI 权限体检”等按钮都会调用 AI 接口并在页面上方展示输出结果。

AI 典型用途：

- 运单履约：生成批量处理顺序和客户沟通话术。
- 收货打单：识别重量差异、重复扫描、资料缺失。
- 渠道排货：推荐渠道、解释成本倒挂、提示批量风险。
- 轨迹监控：解释轨迹超时和生成客户说明。
- 问题件：归类问题原因和生成回复建议。
- 报价查价：自然语言查价和报价差异解释。
- 财务结算：解释费用差异、生成对账摘要。
- 系统设置：检查权限风险和配置冲突。

当前边界：

- AI 输出是辅助建议，不自动替代人工确认。
- 涉及发货、退货、核销、权限修改等高风险动作，仍需人工点击并写入审计。
- 外部 AI 接口异常时，系统会展示本地兜底输出。

## 17. 运单状态字典

| 状态 | 含义 |
| --- | --- |
| DRAFT | 草稿，尚未正式预报 |
| DECLARED | 已预报，等待进入收货流程 |
| WAITING_RECEIVE | 待收货，仓库尚未确认入库 |
| WAITING_SORT | 待排货，需要分配渠道或代理 |
| WAITING_DISPATCH | 待发货，等待出库确认 |
| WAITING_ONLINE | 待上网，已发货但承运商轨迹未上网 |
| WAITING_SIGNED | 待签收，已上网运输中 |
| WAITING_RETURN | 待退货，进入退件流程 |
| PROBLEM | 问题件，需要人工处理 |
| STUCK | 滞留件，长时间未推进 |
| SIGNED | 已签收，流程完成 |
| CANCELLED | 已取消 |

## 18. 当前版本边界与后续规划

当前版本已经具备第一版业务闭环，但仍有部分能力处于预留或模拟阶段：

- 承运商 API：已预留接口，暂不直接调用真实 DHL、UPS、FedEx 等。
- 打印套件：当前支持面单预览和模拟生成，暂不连接真实打印客户端。
- 电子秤：暂未接入真实设备。
- PDA / 手机仓库作业：后续建设移动端或 PDA 页面。

## 19. 推荐使用流程

员工端推荐流程：

1. 基础资料先维护客户、渠道、承运商、费用名称和汇率。
2. 客户或员工创建预报运单。
3. 仓库在收货打单确认入库、复核重量、生成面单。
4. 操作在渠道排货分配渠道、代理、承运商并补齐转单号。
5. 发货后在轨迹监控跟进上网、未更新和签收。
6. 异常票进入问题件中心处理。
7. 报价查价生成应收依据。
8. 财务结算生成应收、对账、收款和核销。
9. 统计报表输出日报和利润分析。
10. 系统管理员在系统设置维护权限、模板、轨迹规则和状态字典。

客户侧推荐流程：

1. 客户登录客户门户。
2. 创建预报运单或查看我的运单。
3. 查看轨迹和转单号。
4. 对异常件进行回复。
5. 查询价格、费用明细、对账单和账户余额。
