# 报价查价：美国 ZIP 派送价格匹配

- 状态：已完成本地实现，未发布、未提交。
- 范围：美国空海运查询固定美国目的地、必填 ZIP/ZIP+4；价格表导入保存邮编规则；精确邮编、最小区间、前缀、全国通用按优先级匹配；结果展示匹配邮编/价格区。
- 数据：`PriceBookRow.postalRule` 已新增本地 Prisma migration；无有效邮编规则的美国空海运行不会作为邮编查询兜底报价；价格表同步体检会提示缺失、格式无法解析及重复邮编范围。
- 验证：Shared build、Web 定向测试、API 定向 E2E、API/Web typecheck、`git diff --check` 均通过。
- 注意：已有历史美国价格表不会自动猜测邮编范围；管理员需重新导入或补录邮编规则后才会被美国邮编查询命中。
