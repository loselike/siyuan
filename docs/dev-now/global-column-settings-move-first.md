# 全局列表列设置移到首行

## 输入

- 任务卡：全局列表列设置增加“移到首行”并保持配置长期生效。

## 完成内容

- 共享 `ManagedTable` 的列设置增加“移到首行”，所有已接入该组件的列表自动生效。
- 选择列强制保持最左侧，操作列强制保持最右侧且不可隐藏或移动；“移到首行”只作用于业务列。
- 共享列设置和列宽的 localStorage 配置按当前登录账号保存；已有旧配置继续可读，账号切换不会继承另一账号的新配置。
- 应用壳运单、客服五个客服列表、运营专线运单池、财务审核列设置和订单费用列设置均补齐“移到首行”。
- 退出登录仅清理 `siyuan-session`，不清理列配置。

## 验证

- 通过：共享列设置定向测试、客服列设置定向测试、Web typecheck、`git diff --check`。
- `warehouse.test.tsx -t "列设置"` 有一条既有断言失败：页面实际列名为“运单号”，测试仍查找“出货单号”；与本轮列设置逻辑无直接关联，未修改仓库业务字段。
- `workspace`、`finance` 的指定筛选当前没有命中用例，Vitest 显示 skipped。
