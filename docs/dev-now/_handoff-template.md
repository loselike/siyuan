## 新会话接管确认

新会话必须先读取 `AGENTS.md`、`.codex-state.md`、`git status --short`、本交接文件和相关代码，然后回复并核对：

1. 当前唯一目标。
2. 已完成内容和效果证据。
3. 仍未完成或未验证内容。
4. 不得覆盖的并发修改。
5. 第一项准确动作。

五项一致后才创建自己的唯一状态文件并继续；接管失败时通知旧会话恢复 `in_progress`，不得归档旧会话。
