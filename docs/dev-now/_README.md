# 代码会话状态目录

本目录按代码会话隔离状态。一个代码会话只认领一个状态文件，一张任务卡或一个非任务卡需求同时只能由一个 `in_progress` 会话落地。

状态文件用于记录输入来源、分支/worktree、允许修改文件、当前状态和验证结果。输入可以是 `docs/tasks/*.md`，也可以是当前会话中的明确实施请求。

禁止事项：

- 修改根索引 `docs/dev-now.md`。
- 删除、覆盖或重写其他会话的状态文件。
- 把多个任务卡或多个会话需求塞进同一个状态文件。
- 用 `.codex-state.md` 抢锁或声明当前任务。

新会话复制 `_template.md` 的结构，并使用唯一业务 slug 命名。状态只允许：`in_progress`、`blocked`、`handed_off`、`complete`。
