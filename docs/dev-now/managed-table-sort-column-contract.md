# 第一阶段：统一业务表排序与列设置

- 范围：仅增强 `ManagedTable`，并接入录单草稿箱、专线运单池。
- 统一约定：每列用唯一 `key` 同时作为显示列、列设置和持久化标识；原始字段用 `dataIndex` 排序，计算列用 `sortValue` 排序，操作列声明 `sortable: false`。
- 第二阶段：已有 `ManagedTable` 对 `key` 与记录原始字段同名的列自动补排序，不要求逐页重写 `dataIndex`；计算列仍必须显式提供 `sortValue`，避免按展示文本产生错误排序。
- 只读 AntD 表首批迁移采用兼容模式：关闭列设置、列宽调整和吸顶，只保留原分页/滚动与字段排序；费用编辑、`Summary` 汇总和表单输入表不在本批处理。
- 不在本阶段处理：其余直接使用 AntD `Table` 的嵌入式/编辑表、其他业务页面、接口服务端排序和字段口径。
- 验收：通用计算列排序/操作列不可排序测试，录单草稿与运单池构建及类型检查。
