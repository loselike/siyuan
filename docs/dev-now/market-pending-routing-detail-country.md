# 市场待排货详情、国家与排货确认

- 状态：已完成（未发布、未提交 Git）
- 范围：待排货国家列、市场排货详情弹窗、成本维护入口与排货前校验；不改仓库出库、付款或应付审核。

## 本轮完成

- 待排货在公司渠道后、货物数据前新增“国家”；空值显示红色“缺国家”。
- 双击待排货行打开市场详情弹窗，包含基本信息、业务成本、应付成本三个页签；国家复用 `destinationCountry` 及既有中英文/别名检索选项。
- 成本页按运单展示业务成本、应付成本及 RMB 合计，并支持市场排货阶段新增、修改、删除未锁定费用；费用操作复用现有单票费用接口与审计。
- 保存排货资料不推进状态；确认排货前强制校验国家、代理、代理渠道、计费重、单价。两套仓储均拒绝缺国家的排货请求。
- `routing:write` 仅在 `WAITING_SORT` 阶段可维护业务成本和应付成本，不开放财务审核、付款或已排货后的成本改动。
