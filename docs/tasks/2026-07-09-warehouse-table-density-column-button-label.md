# 2026-07-09-warehouse-table-density-column-button-label

## 1. 业务目标

仓库模块表格页面减少无效空白，提升信息密度；所有仓库表格的列设置按钮统一命名为 `列设置`，不再显示 `待出库列设置` 这类带模块前缀的文案。

## 2. 使用角色

- 仓库：查看仓库各列表时获得更紧凑的表格布局，并使用统一的 `列设置` 按钮。
- 管理员：同仓库体验。
- 业务员/客服/财务/客户：不涉及本卡。

## 3. 用户流程

1. 用户进入 `仓库管理` 下任意表格页面，例如 `在仓数据`、`待出库`。
2. 页面表格区域应更紧凑，不出现右侧大面积空白列或无意义留白。
3. 用户点击表格右上角 `列设置`。
4. 系统打开当前表格的列设置弹窗。
5. 弹窗标题可以保留具体上下文，例如 `待出库列设置`；但按钮文案统一显示为 `列设置`。

## 4. 业务规则

- 仓库表格应尽量使用可视宽度展示有效字段，不应因为列设置按钮或固定列宽导致右侧出现大面积空白。
- 仓库模块所有列设置按钮统一显示为 `列设置`，不再显示 `待出库列设置`、`在仓列设置`、`今日收货列设置` 等长文案按钮。
- 列设置显示/隐藏、列顺序、列宽等现有能力保持不变。
- 优先处理 `仓库管理 -> 待出库` 的空白和按钮文案；同步检查仓库模块其他表格。
- 本卡只改布局和按钮文案，不改变字段权限、接口数据、状态流转或财务口径。

## 5. 不做范围

- 不发布 47。
- 不改待出库字段定义。
- 不改批量出货。
- 不改代理交接单。
- 不改已出库历史。
- 不改今日收货/在仓数据业务逻辑。
- 不改数据库字段或迁移。
- 不新增或删除业务字段。
- 不通过布局调整展示仓库无权查看的财务敏感字段。

- 验收 1：`仓库管理 -> 待出库` 右上角按钮文案显示为 `列设置`，不显示 `待出库列设置`。
- 验收 2：仓库模块其他表格列设置按钮也统一显示为 `列设置`。
- 验收 3：点击 `列设置` 仍能打开对应表格的列设置弹窗。
- 验收 4：列设置弹窗功能保持不变。
- 验收 5：`待出库` 表格右侧不再出现大面积无意义空白列。

- 验收 7：页面横向滚动仍可使用，不遮挡固定列、操作列或列设置按钮。
- 验收 8：本卡不改变待出库数据、出货流程、字段权限和财务敏感字段显隐。
