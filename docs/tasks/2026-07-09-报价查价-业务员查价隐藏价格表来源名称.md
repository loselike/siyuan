# 2026-07-09-报价查价-业务员查价隐藏价格表来源名称

## 1. 业务目标

业务员查价成功后不再看到上传价格表名称、代理源文件名或内部价格来源，只提示查价成功并展示可报价结果，避免内部成本来源和价格表文件信息泄露。

## 2. 使用角色

- 业务员/普通查价角色：可查价、看销售报价、时效、渠道要求；不能看到上传价格表名称、源文件名、内部代理名、成本、毛利、加价规则。
- 管理员：可继续查看内部价格来源、成本、毛利、加价命中。
- 市场/报价角色：可继续查看价格表管理、价格表名称、内部代理和来源信息。
- 仓库、客服、财务、客户：本卡不新增报价查价权限。

## 3. 用户流程

1. 业务员进入 `报价查价 -> 查价`。
2. 选择 `亚马逊查询 / 欧洲海运超大件查询 / 欧洲空海运铁路快递查询` 任一模块。
3. 填写查价条件并点击查询。
4. 查询成功后 toast 只显示类似 `查价成功，已输出报价`。
5. 报价结果继续正常展示销售价、渠道、重量段、时效、渠道要求。
6. 页面、toast、详情弹窗、复制报价中不出现上传价格表名称或内部来源名称。

## 4. 业务规则

- 业务员查价成功 toast 不展示价格表名称、源文件名、内部代理名。
- 普通角色可继续看到报价金额、时效、渠道要求和可报价线路。
- 非管理员/非市场报价角色不得看到 `sourceFile`、价格表文件名、内部代理名、成本、毛利、加价规则、raw 数据。
- 前端隐藏不是安全边界；后端返回给普通查价角色的数据也不能包含敏感来源字段。
- 管理员和市场/报价角色可继续在价格表管理、查看线路、详情中看到内部来源信息。
- 不改变报价金额、计费重、加价、毛利、排序、推荐规则。
- 本卡只改展示与字段裁剪，不新增审计动作。

## 5. 不做范围

- 不改价格表导入逻辑。
- 不改查价模块分类规则。
- 不改报价金额和加价规则。
- 不回填历史价格表。
- 不发布 47。
- 不新增数据库字段。

## 7. 验收标准

- 验收 1：业务员亚马逊查价成功 toast 只显示安全成功文案，不出现 `拓普达`、价格表文件名或内部代理名。
- 验收 2：业务员欧洲海运超大件查价成功 toast 不出现价格表来源名称。
- 验收 3：业务员欧洲空海运铁路快递查价成功 toast 不出现价格表来源名称。
- 验收 4：业务员报价结果仍正常显示销售报价、时效、渠道要求。
- 验收 5：业务员页面和详情弹窗不显示成本、毛利、内部代理、sourceFile、raw 数据。
- 验收 6：管理员/市场仍可在价格表管理和内部详情中查看来源信息。
- 验收 7：报价金额、排序、推荐结果不因本卡变化。
- 验收 8：复制推荐报价不包含价格表文件名或内部来源名称。
