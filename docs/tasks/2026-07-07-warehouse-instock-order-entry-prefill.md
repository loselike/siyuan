# 2026-07-07-warehouse-instock-order-entry-prefill.md

## 1. 业务目标

在 `仓库管理 -> 在仓数据` 中把框选的 `合票` 操作改为 `录单`，支持单票和批量勾选后跳转到 `业务管理 -> 录单`，并默认带入已选择的在仓包裹数据。

## 2. 使用角色

- 管理员：可在在仓数据中单票/批量录单，跳转录单页并带入包裹。
- 有录单权限的业务/客服/运营角色：可使用录单入口，按现有录单权限和字段裁剪。
- 仓库角色：如果没有录单权限，不应看到或不能使用录单入口；不得因此开放财务敏感字段。
- 财务/客户：本卡不新增仓库在仓录单入口权限。

## 3. 用户流程

1. 用户进入 `仓库管理 -> 在仓数据`。
2. 表格顶部原 `合票` 按钮改为 `批量录单`。
3. 表格行内原 `合票` 按钮改为 `录单`。
4. 用户勾选多个在仓包裹后点击 `批量录单`：
   - 系统跳转到 `业务管理 -> 录单`。
   - 录单页的仓库数据默认选中刚才勾选的包裹。
   - 顶部已选货物、总件数、实重、方数、计费重按选中包裹自动汇总。
5. 用户点击单行 `录单`：
   - 系统跳转到 `业务管理 -> 录单`。
   - 录单页默认选中该行包裹。
6. 如果没有勾选包裹就点击 `批量录单`，提示 `请先勾选需要录单的包裹`。
7. 如果所选包裹已绑定其他运单或草稿，沿用现有录单页/后端校验提示，不重复绑定。
8. 录单页默认带入在仓包裹后，如果包裹是理货后生成的数据：
   - 在快递单号/客户编号-快递单号旁显示 `理` 标记。
   - `理` 标记贴近包裹号，不放到无关列。
   - 点击该包裹号或 `理` 标记，可查看该包裹对应的理货历史。

## 4. 业务规则

- 文案规则：
  - 仅本卡截图框选位置改名：顶部 `合票` -> `批量录单`，行内 `合票` -> `录单`。
  - 录单弹窗/提示不得再写“确认合票”“只做仓库合票”。
- 行为规则：
  - 点击 `录单/批量录单` 不再创建仓库合票记录。
  - 不再停留仓库页弹出合票弹窗。
  - 必须跳转到 `业务管理 -> 录单`，并把选中的 `warehousePackageIds` 作为预选数据。
  - 录单页只预填仓库包裹数据，不自动提交审核。
- 数据规则：
  - 选中包裹仍保持在仓状态，直到录单保存草稿或提交审核后按现有录单逻辑处理。
  - 多个包裹支持一起带入同一张录单。
  - 已绑定运单、已出库、已归档包裹不能重复录单，沿用后端校验。
- 权限边界：
  - 菜单权限不能代替接口权限；后端录单接口仍必须校验角色和客户/业务员归属。
  - 仓库页面不得显示应收、应付、利润、代理成本等财务敏感字段。
- 审计：
  - 跳转动作本身不强制新增审计。
  - 保存录单草稿或提交审核沿用 `shipment.order_entry.draft / submit` 等现有审计。
- 理货标记：
  - 满足 `tallyTaskId`、`tallyTaskNo` 或 `tallyStatus = 已理货` 的包裹，都视为理过货。
  - 录单页、仓库数据选择弹窗、已选货物列表中都要保留 `理` 标记。
- 理货历史：
  - 点击理过货包裹时，展示来源理货任务、来源组合号、理货需求、原始件重尺、理货后件重尺、完成时间、标签应用时间、覆盖后包裹号。
  - 如果没有找到完整理货任务，也要展示包裹自身已有的理货字段，并提示 `理货任务记录待补全`。
  - 录单用户只能查看与当前可见包裹关联的理货历史。

## 5. 不做范围

- 不发布 47。
- 不改财务金额口径。
- 不改录单提交审核规则。
- 不自动提交录单。
- 不新增数据库字段或迁移，优先复用现有 `prefillOrderEntryPackageIds` 和 `warehousePackageIds`。
- 不改未完成理货、已完成理货、待出库、收货交接单流程。
- 不批量改所有历史“合票”业务术语，只处理截图框选的在仓数据录单入口。

## 7. 验收标准

- 验收 1：`在仓数据` 顶部显示 `批量录单`，不显示顶部 `合票`。
- 验收 2：每行操作显示 `录单`，不显示行内 `合票`。
- 验收 3：勾选多条在仓包裹后点击 `批量录单`，自动跳转到 `业务管理 -> 录单`。
- 验收 4：录单页默认选中刚才勾选的包裹，并正确汇总已选货物、件数、实重、方数、计费重。
- 验收 5：点击单行 `录单` 后，录单页默认只带入该行包裹。
- 验收 6：未勾选时点击 `批量录单`，提示用户先勾选包裹。
- 验收 7：录单页保存草稿/提交审核仍走现有后端校验，已绑定包裹不能重复录单。
- 验收 8：仓库在仓页面仍不展示财务敏感字段。
- 验收 9：从在仓数据点击单票/批量录单进入录单页后，理过货包裹在快递单号/包裹号旁显示 `理`。
- 验收 10：点击 `理` 标记或该包裹号，可以看到理货历史详情。
- 验收 11：非理货包裹不显示 `理` 标记。
- 验收 12：理货历史详情不展示应收、应付、利润、代理成本等财务敏感字段。
