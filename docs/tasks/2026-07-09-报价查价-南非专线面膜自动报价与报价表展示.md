# 2026-07-09-报价查价-南非专线面膜自动报价与报价表展示

## 1. 业务目标

南非专线查询中，用户输入品名 `面膜` 并填写体积后，系统自动匹配化妆品类报价规则，按指定报价模板输出结果，并在页面展示完整南非报价表；同时南非查询表单去掉 `重量 KG` 和 `备注/申报信息`。

## 2. 使用角色

- 业务员、客服、运营：可进入报价查价，输入品名和体积，查看南非专线业务报价结果和只读报价表。
- 市场、管理员：除查询外，继续按现有权限维护南非价格规则和图片价格表。
- 无报价权限角色：不能进入报价查价，也不能通过接口绕过权限查看报价。
- 普通业务角色不得看到价格表来源、内部成本、毛利、代理底价等内部字段。

## 3. 用户流程

1. 用户进入 `报价查价 -> 查价 -> 南非专线查询`。
2. 页面表单只保留 `品名/明细关键词`、`指定物料类别`、`体积 CBM`。
3. 页面去掉 `重量 KG` 和 `备注/申报信息`。
4. 用户输入 `面膜`，体积填写 `1.000`。
5. 系统自动匹配启用中的南非物料规则：`化妆品类 / 化妆品类`，关键词包含 `面膜`。
6. 页面自动展示报价结果；点击 `查询报价` 也应得到同一结果，不能重复生成错乱结果。
7. 报价结果下方展示完整南非报价表，当前命中的 `化妆品类 / 化妆品类` 行高亮。

## 4. 业务规则

- 南非专线匹配只使用启用中的南非物料规则。
- `面膜` 必须命中 `化妆品类 / 化妆品类`。
- 南非专线本卡不再使用重量参与计费；计费方按体积 CBM 计算，并保留低消 `0.5CBM` 口径。
- 当体积为 `1.000` 时，计费方为 `1.000CBM`。
- 运费单价为 `¥3500.00/CBM` 时，运费为 `¥3500.00`。
- 报价结果展示和复制文案必须按以下格式输出：

```text
南非SA海运DDP专线：面膜
分类：化妆品类/化妆品类
计费方：1.000CBM
运费：¥3500.00/CBM，运费 ¥3500.00
备注：无牌无侵权；低消0.5CBM  报关件需要单询。
```

- 南非业务报价结果不展示风险费、单证费用、预估合计等旧口径字段。
- 如果没有匹配规则，页面提示 `未匹配到南非物料规则`，仍展示完整报价表供人工判断。
- 如果多个规则同时命中，优先使用更精确关键词命中的规则；页面需展示命中关键词和最终采用规则。
- 查询是读操作，默认不新增审计；如果现有报价查询已有日志或链路事件，则继续记录命中规则、关键词、计费方和操作人，不能记录内部成本敏感字段。
- 南非规则启停只影响后续查询和选择，不回写历史报价结果。

## 5. 不做范围

- 不发布 47。
- 不改亚马逊、欧洲海运、欧洲空海运铁路快递的查询表单。
- 不做 AI 模糊识别，只做关键词规则匹配。
- 不改历史报价记录。
- 不改代理加价、价格表导入、客户账号绑定。
- 不把南非报价表管理操作搬到查询页；查询页只读展示完整报价表。

## 7. 验收标准

- 验收 1：南非专线查询页面不再显示 `重量 KG` 和 `备注/申报信息` 两个字段。
- 验收 2：输入 `面膜`、体积 `1.000` 后，系统自动显示报价结果，分类为 `化妆品类/化妆品类`，运费为 `¥3500.00`。
- 验收 3：报价结果和复制内容严格符合指定 5 行模板，不再出现风险费、单证费用、预估合计。
- 验收 4：页面展示完整南非报价表，命中的面膜规则行高亮。
- 验收 5：普通业务角色看不到价格表来源、成本、毛利等内部字段。
- 验收 6：停用的南非物料规则不会被自动命中。
