# 2026-07-07-warehouse-dispatch-table-fields.md

## 1. 业务目标

`仓库管理 -> 待出库` 表格严格按用户给定表格字段和顺序落地，并补充 `唛头` 字段，让仓库按待出库业务数据快速扫读、排序和设置列显隐。

## 2. 使用角色

- 仓库：可查看待出库表格、勾选行、调整列显示/隐藏和排序。
- 管理员：同仓库权限。
- 业务员/客服：不操作仓库待出库表格。
- 财务：不参与本卡，不查看代理成本、利润、应付等财务敏感字段。
- 客户：不查看仓库内部待出库表格。

## 3. 用户流程

1. 仓库进入 `仓库管理 -> 待出库`。
2. 页面展示待出库订单表格。
3. 表格默认按指定字段顺序展示：选择、运单创建时间、业务员、运单号、代理、代理渠道、客户编号、目的地、渠道、业务数据（件数、总量、体积、计费重）、唛头、品名、报关、敏感。
4. 仓库可通过列设置控制字段显示/隐藏。
5. 仓库可按主要字段排序，便于按时间、业务员、代理、目的地、件数、计费重等维度查看。

## 4. 业务规则

- `选择`：行勾选框，保留现有选择能力；本卡不新增出货动作。
- `运单创建时间（同步运单录入日期）`：展示运单创建/录入时间。
- `业务员`：展示运单所属业务员。
- `运单号`：展示系统运单号/出货单号。
- `代理`：展示市场排货选择的代理。
- `代理渠道`：展示代理侧渠道。
- `客户编号`：展示客户编号。
- `目的地`：展示目的国家/目的地。
- `渠道`：展示业务渠道。
- `业务数据`：作为分组表头，包含 `件数`、`总量`、`体积`、`计费重`。
- `唛头`：展示是否需要贴唛头；需要时显示明确标签。
- `品名`：展示运单品名。
- `报关`：展示是否报关/退税。
- `敏感`：展示敏感货标识。
- 默认字段顺序必须严格按本卡字段顺序，`业务数据` 必须是分组表头。
- 列设置至少覆盖除 `选择` 外的业务字段。
- 排序至少覆盖：运单创建时间、业务员、运单号、代理、客户编号、目的地、件数、总量、体积、计费重。
- `warehouse:read` 可查看待出库表格；无 `warehouse:write` 用户不应看到会触发出库的操作；本卡不改变现有写权限逻辑。
- 本卡不涉及应收、应付、利润、代理成本；待出库表格不得展示财务敏感字段。

## 5. 不做范围

- 不发布 47。

- 不移除 `收货交接单` 二级目录。
- 不做代理交接单弹窗。

- 不改出货按钮、批量出库、状态流转。
- 不改市场排货规则。
- 不改财务口径。
- 不新增客户侧展示。
- 不新增数据库字段或迁移，除非现有字段完全无法支撑本表格字段。

## 7. 验收标准

- 验收 1：`待出库` 表格默认按指定顺序展示字段。
- 验收 2：`业务数据` 以分组表头展示，下面包含 `件数 / 总量 / 体积 / 计费重`。
- 验收 3：表格包含 `唛头` 列，需贴唛头订单有明确标识。
- 验收 4：表格支持列显示/隐藏设置。
- 验收 5：主要字段支持排序或保持现有可排序能力。
- 验收 6：仓库待出库表格不展示应收、应付、利润、代理成本等财务敏感字段。
- 验收 7：本卡不改变出货、交接单、已出库、状态流转相关行为。
