# 2026-07-07-warehouse-batch-dispatch-archive.md

## 1. 业务目标

仓库 `待出库` 严格按业务指定字段展示待出库订单，支持勾选后批量出库；出库时自动弹出代理交接单并打印，确认出库后的订单进入仓库 `已出库` 历史存档，移除单独的 `收货交接单` 二级目录。

## 2. 使用角色

- 仓库：可查看待出库表格、批量勾选待出库订单、打印代理交接单、确认出库、查看已出库历史。
- 管理员：同仓库权限。
- 业务员/客服：不操作仓库出库，只能在各自流程查看出库后的业务结果。
- 财务：不参与本卡，不查看代理成本、利润、应付等财务敏感字段。
- 客户：不查看代理交接单内部内容，只能看到后续客户可见物流状态。

## 3. 用户流程

1. 仓库进入 `仓库管理 -> 待出库`。
2. `待出库` 表格按指定字段展示：勾选框、运单创建时间、业务员、运单号、代理、代理渠道、客户编号、目的地、渠道、业务数据、唛头、品名、报关、敏感。
3. 仓库可通过列设置控制字段显示/隐藏和排序。
4. 仓库勾选一票或多票待出库订单，顶部显示 `已选 X 票 / Y 件`。
5. 未勾选时点击 `出货`，系统提示 `请先勾选待出库订单`。
6. 勾选后点击顶部 `出货`。
7. 系统弹出 `代理交接单`，按代理/渠道拆分，并自动填入系统数据。
8. 交接单格式按截图展示：
   - 标题：`深圳思远国际货运代理有限公司`
   - 顶部字段：`代理`、`出货时间`
   - 明细列：`运单号`、`入仓号`、`渠道`、`品名`、`件数`、`是否报关退税`、`备注`、`目的地`
   - 底部汇总：`票数`、`件数`
   - 签收栏：`收件人：`，默认留空，打印后现场手填
9. 仓库点击 `打印` 后打开打印窗口，并完成本批出库。
10. 已出库订单从 `待出库` 移除，进入 `仓库管理 -> 已出库`。
11. 仓库左侧二级目录移除 `收货交接单`；`已出库` 成为仓库管理最后一个二级目录。

## 4. 业务规则

- 菜单结构：
  - `待出库` 后新增 `已出库`。
  - 删除/隐藏单独的 `收货交接单` 二级目录。
  - `已出库` 为仓库管理最后一个二级目录。
- 待出库表格字段：
  - `选择`：行勾选框，用于批量出库。
  - `运单创建时间（同步运单录入日期）`：展示运单创建/录入时间。
  - `业务员`：展示该票所属业务员。
  - `运单号`：展示系统运单号/出货单号。
  - `代理`：展示市场排货选择的代理。
  - `代理渠道`：展示代理侧渠道。
  - `客户编号`：展示客户编号。
  - `目的地`：展示目的国家/目的地。
  - `渠道`：展示业务渠道。
  - `业务数据`：分组表头，包含 `件数`、`总量`、`体积`、`计费重`。
  - `唛头`：展示是否需要贴唛头；需要时显示明确标签。
  - `品名`：展示运单品名。
  - `报关`：展示是否报关/退税。
  - `敏感`：展示敏感货标识。
- 表格设置：
  - 支持列显示/隐藏设置。
  - 支持按字段排序，至少覆盖运单创建时间、业务员、运单号、代理、客户编号、目的地、件数、总量、体积、计费重。
  - 默认字段顺序必须按本卡字段顺序展示。
- 状态流转：
  - 仅 `WAITING_DISPATCH` 的订单可在 `待出库` 出货。
  - 打印代理交接单并确认出库后，运单进入 `OUTBOUNDED`。
  - 对应仓库包裹进入 `SHIPPED`。
- 批量勾选：
  - 顶部批量勾选只选择当前筛选/当前页可出货订单。
  - 已出货、无权限、非待出库订单不可被勾选。
  - 行内单选仍保留。
- 交接单分组：
  - 按代理优先分组；同代理下如渠道不同，仍在明细行展示各自渠道。
  - 代理缺失时显示 `待确认代理`，但仍允许打印，方便仓库按现场资料处理。
- 字段默认填充：
  - `运单号`：系统出货单号/运单号。
  - `入仓号`：关联在仓包裹号、入仓号或来源组合号。
  - `渠道`：市场排货后的业务渠道/代理渠道。
  - `品名`：运单品名；缺失显示 `-`。
  - `件数`：出货件数。
  - `是否报关退税`：按运单报关/退税字段转换为 `是/否`，缺失显示 `否`。
  - `备注`：仓库备注、出货备注或唛头提示；缺失显示空。
  - `目的地`：目的国家。
  - `出货时间`：打印时的北京时间。
  - `收件人`：不自动填系统数据，交接单保留空白手填。
- 唛头：
  - `待出库` 表格必须展示唛头字段。
  - 如果所选订单包含 `需贴唛头`，弹窗内必须先确认 `已贴唛头`，否则不能打印出货。
- 已出库归档：
  - `已出库` 是仓库阶段历史存档。
  - 已出库列表应按 `outboundAt/dispatchedAt` 或出库审计识别，不只依赖当前运单状态，避免后续客服/物流状态推进后从仓库历史消失。
  - 已出库展示出货单号、客户/目的地、件数、计费重、渠道、代理、出库时间、操作人、交接单号/审计信息。
- 权限：
  - 只有 `warehouse:write` 可批量勾选和出货。
  - `warehouse:read` 可查看待出库和已出库。
  - 无写权限用户只能查看待出库/已出库，不显示批量勾选和出货按钮。
- 审计：
  - 批量出货每票仍记录 `shipment.dispatch`。
  - 审计中包含 `handoverNo`、出货单号、代理/渠道、批量出货来源、出库人、出库时间。
- 客户可见结果：
  - 客户只看到出货后的公开物流状态，不看到代理交接单、内部备注、唛头确认和审计内容。
- 费用口径：
  - 本卡不涉及应收、应付、利润、代理成本。
  - 仓库页面不得展示财务敏感字段。

## 5. 不做范围

- 不发布 47。
- 不改市场排货规则。
- 不改财务口径。
- 不新增客户侧交接单展示。
- 不做真实承运商接口。
- 不处理已出库历史交接单重打。
- 不改 `今日收货`、`在仓数据`、`理货` 主流程。
- 不新增数据库字段或迁移，除非现有字段无法稳定支持待出库指定字段或已出库历史查询。

## 6. 工程落地点

- Web：
  - `apps/web/src/modules/warehouse/WarehousePage.tsx`
  - `仓库管理 -> 待出库` 表格字段、字段顺序、列设置、排序、顶部批量勾选、已选统计、出货按钮。
  - 代理交接单弹窗和打印动作。
  - 新增 `已出库` 二级目录。
  - 移除 `收货交接单` 二级目录。
  - 交接单打印样式需贴近截图，黑白表格、横向 A4、粗边框、大标题。
- API：
  - 复用现有 `POST /api/shipments/:id/dispatch`。
  - 如现有批量只循环调用单票接口，保持单票审计完整。
  - 如待出库表格缺字段，优先复用现有运单、排货、仓库包裹字段补齐响应。
  - 如需已出库列表数据，优先复用现有运单/仓库查询能力，按出库时间或出库审计筛选仓库历史。
- Shared：
  - 优先复用现有 `Shipment`、`ShipmentDispatchInput`、待出库/已出库相关状态枚举。
- 测试：
  - `apps/web/src/modules/warehouse/warehouse.test.tsx`
  - `apps/api/src/modules/app.warehouse.e2e.test.ts`

- 验收 1：仓库二级目录中 `待出库` 后新增 `已出库`，且 `收货交接单` 不再显示。

- 验收 4：`待出库` 表格支持列显示/隐藏设置，并支持主要字段排序。
- 验收 5：`待出库` 可批量勾选订单，并显示 `已选 X 票 / Y 件`。
- 验收 6：未勾选时点击顶部 `出货`，提示 `请先勾选待出库订单`。
- 验收 7：勾选多票后点击 `出货`，弹出 `代理交接单`，并按代理/渠道展示一张或多张交接单。
- 验收 8：交接单自动填入运单号、入仓号、渠道、品名、件数、是否报关退税、备注、目的地、票数、件数；`收件人：` 栏保留空白，可打印后手填。
- 验收 9：点击 `打印` 打开打印窗口，打印内容包含截图格式的黑白代理交接单。
- 验收 10：打印动作完成后，所选订单离开 `待出库` 队列，状态进入 `OUTBOUNDED`，并出现在 `已出库`。
