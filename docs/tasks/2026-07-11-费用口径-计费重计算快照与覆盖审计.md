# 计费重计算快照与人工覆盖审计

## 1. 业务目标
让每一笔应收、业务成本和应付都能解释采用了什么重量、规则和人工修改。

## 2. 使用角色
业务员查看本人订单应收/业务计费重，可按权限申请或修改；市场查看排货所需业务/代理计费重；财务查看全部并审计；仓库只提供实重和尺寸；客服只读运输必要重量。

## 3. 用户流程
仓库重量尺寸进入订单→系统按渠道规则计算自动计费重→页面展示计算依据→有权限者填写覆盖值和必填原因→费用引用明确重量快照→详情和日志可回看。

## 4. 业务规则
- 保存规则 ID/版本、实重、体积重、系数、最低重、自动结果、覆盖结果、原因、人和时间。
- 应收、业务、应付可引用不同规则，但不能只保存最终数字。
- 人工覆盖不得修改仓库原始实重/尺寸；重复提交幂等。
- 业务员不得读取代理计费规则和代理成本。
- 计算规则变更不回溯覆盖已审核费用。

## 5. 不做范围
不重做价格表；不自动重算历史已审核费用；不改汇率和币种口径；不发布 47。

## 6. 工程落地点
Shared 计算结果类型、Prisma 快照字段/模型及迁移、订单/排货/费用 API、字段裁剪、审计、订单/报价/财务 E2E。

## 7. 验收标准
- 同一输入和规则版本得到稳定结果，并能展示完整计算过程。
- 覆盖必须有原因，保存前后值和操作人；无权限直接 API 调用被拒绝。
- 应收、业务、应付明确引用的重量来源，财务可追溯。
- 历史记录读取兼容，未迁移历史不伪造算法来源。
