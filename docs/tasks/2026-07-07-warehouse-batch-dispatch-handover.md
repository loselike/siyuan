# 2026-07-07-warehouse-batch-dispatch-handover.md

## 1. 业务目标

仓库 `待出库` 支持批量勾选待出库订单，点击 `出货` 后自动生成代理交接单，按系统数据默认填表，打印后完成出货。

## 2. 使用角色

- 仓库：可批量勾选待出库订单、生成代理交接单、打印并完成出货。
- 管理员：同仓库权限。
- 业务员/客服：不操作仓库批量出货，只能在各自流程查看出货后的业务结果。
- 财务：不参与本卡，不查看代理成本、利润、应付等财务敏感字段。
- 客户：不查看代理交接单内部内容，只能看到后续客户可见轨迹/出货结果。

## 3. 用户流程

1. 仓库进入 `仓库管理 -> 待出库`。
2. 表格上方显示批量勾选入口，可一键勾选当前页可出货订单，也可取消勾选。
3. 仓库勾选一批待出库订单后，顶部显示 `已选 X 票 / Y 件`。
4. 仓库点击顶部 `出货`。
5. 系统弹出 `代理交接单`，按代理/渠道拆分交接单，并自动填入系统数据。
6. 交接单格式按截图展示：
   - 标题：`深圳思远国际货运代理有限公司`
   - 顶部字段：`代理`、`出货时间`
   - 明细列：`运单号`、`入仓号`、`渠道`、`品名`、`件数`、`是否报关退税`、`备注`、`目的地`
   - 底部汇总：`票数`、`件数`
   - 签收栏：`收件人：`，默认留空，打印后现场手填
7. 仓库点击 `打印` 后打开打印窗口；打印动作完成本批出货，订单离开待出库队列。
8. 若未勾选订单直接点击 `出货`，提示 `请先勾选待出库订单`。

## 4. 业务规则

- 状态流转：
  - 仅 `WAITING_DISPATCH` 的订单可进入待出库批量出货。
  - 打印代理交接单后，所选运单进入 `OUTBOUNDED`。
  - 对应仓库包裹状态更新为 `SHIPPED`。
- 批量勾选：
  - 顶部批量勾选只选择当前筛选/当前页可出货订单。
  - 已出货、无权限、非待出库订单不可被勾选。
  - 行内单选仍保留。
- 交接单分组：
  - 按代理优先分组；同代理下如渠道不同，仍在明细行展示各自渠道。
  - 代理缺失时显示 `待确认代理`，但仍允许打印，方便仓库按现场资料处理。
- 字段默认填充：
  - `运单号`：系统出货单号/运单号。
  - `入仓号`：关联在仓包裹号、入仓号或来源组合号。
  - `渠道`：市场排货后的业务渠道/代理渠道。
  - `品名`：运单品名；缺失显示 `-`。
  - `件数`：出货件数。
  - `是否报关退税`：按运单报关/退税字段转换为 `是/否`，缺失显示 `否`。
  - `备注`：仓库备注、出货备注或麦头提示；缺失显示空。
  - `目的地`：目的国家。
  - `出货时间`：打印时的北京时间。
  - `收件人`：不自动填系统数据，交接单保留空白手填。
- 麦头：
  - 如果所选订单包含 `需贴麦头`，弹窗内必须先确认 `已贴麦头`，否则不能打印出货。
- 审计：
  - 批量出货每票仍记录 `shipment.dispatch`。
  - 审计中包含 `handoverNo`、出货单号、代理/渠道、批量出货来源。
- 权限：
  - 只有 `warehouse:write` 可批量勾选和出货。
  - 无写权限用户只能查看待出库，不显示顶部批量勾选和出货按钮。
- 客户可见结果：
  - 客户只看到出货后的公开物流状态，不看到代理交接单、内部备注、麦头确认和审计内容。
- 费用口径：
  - 本卡不涉及应收、应付、利润、代理成本。

## 5. 不做范围

- 不发布 47。
- 不改市场排货规则。
- 不改财务口径。
- 不新增数据库字段或迁移，优先复用现有出货和审计字段。
- 不做真实承运商接口。
- 不做客户侧交接单展示。
- 不处理已出货历史交接单重打。
- 不改 `今日收货`、`在仓数据`、`理货` 主流程。

## 6. 工程落地点

- Web：
  - `apps/web/src/modules/warehouse/WarehousePage.tsx`
  - `仓库管理 -> 待出库` 顶部批量勾选、已选统计、出货按钮、代理交接单弹窗、打印动作。
  - 交接单打印样式需贴近截图，黑白表格、横向 A4、粗边框、大标题。
- API：
  - 复用现有 `POST /api/shipments/:id/dispatch`。
  - 如现有批量只循环调用单票接口，保持单票审计完整。
- Shared：
  - 优先复用现有 `Shipment`、`ShipmentDispatchInput`、待出库状态枚举。
- 测试：
  - `apps/web/src/modules/warehouse/warehouse.test.tsx`

## 7. 验收标准

- 验收 1：`待出库` 表格上方出现批量勾选入口，可一键勾选当前页待出库订单并更新 `已选 X 票 / Y 件`。
- 验收 2：未勾选时点击顶部 `出货`，提示 `请先勾选待出库订单`。
- 验收 3：勾选多票后点击 `出货`，弹出 `代理交接单`，并按代理/渠道展示一张或多张交接单。
- 验收 4：交接单自动填入运单号、入仓号、渠道、品名、件数、是否报关退税、备注、目的地、票数、件数；`收件人：` 栏保留空白，可打印后手填。
- 验收 5：点击 `打印` 打开打印窗口，打印内容包含截图格式的黑白代理交接单。
- 验收 6：打印动作完成后，所选订单离开 `待出库` 队列，状态进入 `OUTBOUNDED`。
- 验收 7：包含需贴麦头订单时，未确认 `已贴麦头` 不能打印出货。
- 验收 8：无 `warehouse:write` 权限用户看不到批量勾选和出货按钮。
- 验收 9：仓库待出库和交接单不展示应收、应付、利润、代理成本等财务敏感字段。
