# 查价通用时效与渠道要求兼容

状态：已发布 47。

- 范围：亚马逊、欧洲超大件、欧洲空海运铁路快递、美国空海运、加拿大空海运；按用户要求不改南非与迪拜。
- 时效：主运输承诺与私人地址末端承诺合并为区间，例如“开船后第二天开始算30天；私人地址派送时效40天”展示为 `30-40天`；`航程时效28-33天` 可简化为 `时效28-33天`。
- 渠道要求：价格表最后一个有效价格行后的连续段落作为该价格区块的渠道要求，不再依赖“渠道说明/渠道限制”等固定标题；覆盖通用表、横向小表及拓普达、振韵、驰汉专用解析分支。
- 已递增五个目标模块的解析规则版本，以便保留源文件自动回刷历史价格表；南非和迪拜版本未因本规则升级。
- 发布：本机存在无关 Web、Shared 和迁移改动，故仅同步 `apps/api/src/modules/pricing-excel.ts`，无迁移、未重启 Web。首次构建受 Docker 缓存影响，已改为无缓存构建定位 Shared 版本差异后，以兼容旧 Shared 的最小解析器补丁成功重建 API。
- 发布后验证：容器及公网 `http://47.120.33.111:8899/api/health` 均为 200；容器内实测时效输出 `30-40天`，五个目标模块解析版本已生效。
