# 排货费用即时显示

- 需求：市场排货弹窗新增、修改或删除业务成本/应付成本后，费用表和合计不再需要关闭重开才刷新。
- 实现：保存接口返回费用行后立即更新当前运单的财务明细缓存；删除时同步从缓存移除；保留工作台全局刷新。
- 验证：`npm run typecheck -w @siyuan/web` 通过；`git diff --check` 通过。新增定向 Vitest 用例已覆盖保存后费用行无需重开弹窗即可显示，但当前仓库的 Vitest worker 会在启动后持续占用、不返回结果（已终止本次测试进程）；此前完整路由套件为 9/10 通过，唯一失败项是市场看板跳转到待排货区域的既有断言，和费用缓存无关。
