## 当前进度

- 已允许当前在仓的已理货包裹再次发起理货；原始归档包裹、已合票和已出库包裹仍不可处理。
- 二次理货一次仅允许选择一个已理货包裹，未完成任务仍阻止重复发起。
- 编号示例：`13990622LH -> 13990622LH02 -> 13990622LH03`；同日第二个独立任务 `1399062202LH` 二次理货生成 `1399062202LH02`。
- 新任务继续以当前包裹为来源，完成后沿用既有来源包裹链和审计记录。
- “理”详情改为按包裹来源逐层查询，按第一次到当前轮次展示完整件重尺、任务、标签和覆盖记录。
- 多轮归档时保留来源包裹原所属任务，不再用新任务号覆盖旧关联；链路查询最多追溯 20 层并防止循环。
- 理货完成只提交保留/合并/拆分结果，不再要求仓库提前填写重量和长宽高；后端原子创建 `PENDING_REMEASURE` 输出包裹并归档来源包裹。
- 完成后自动生成并打印 100mm x 150mm Code 128 标签；多个输出包裹使用唯一 `-01/-02` 后缀，保证设备回传可以精确匹配。
- 墨家按条码回传后覆盖对应待复测包裹的重量、尺寸、方数和计费重；相同数据重复回传幂等，不同数据重复回传转人工确认。
- 待复测包裹禁止再次理货、拆票、合票、出库和录单；人工补全正数重量尺寸时复用同一覆盖逻辑。
- 所有任务输出完成复测后回写任务汇总和标签应用信息；标签扫描接口只返回已有包裹，不再创建重复包裹。
- “已完成理货”任务列表直接携带并可展开查看对应结果包裹；墨家或人工复测覆盖后，逐包裹显示最新重量、尺寸、体积、计费重、来源、设备/操作人和覆盖时间。
- 已完成理货模块打开期间每 5 秒刷新任务及结果包裹；单个包裹过机后立即显示局部复测进度，全部完成后同步刷新任务汇总。
