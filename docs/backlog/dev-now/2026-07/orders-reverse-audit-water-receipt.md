# 运单管理反审核与水单后置匹配

## 输入与口径

- 用户提供任务卡“运单管理权限裁剪、操作列收敛、反审核回退与水单后置匹配”。
- 用户特例授权执行，采用最小验证：订单/财务 Web 与 API 定向测试、Web/API 类型检查、`git diff --check`。
- 业务员在水单到账查询新增本人客户水单，可选上传凭证；财务确认到账后才进入自动/手动匹配。

## 完成记录（2026-07-12）

- 运单管理操作列收敛为“反审核 / 操作日志”，移除列表内收款、审核通过、审核不通过、删除和修改入口；反审核仅对 `WAITING_SORT` 显示。
- 新增服务端 `POST /shipments/:id/review/reverse`：管理员、订单归属业务员或具备 `orders:review:reverse` 权限的角色可将待排货运单回退到 `REVIEW_PENDING`；已进入后续状态、财务确认或已匹配收款时拒绝。可安全释放的待排货代理成本、代理/渠道占用会同步解除，并写入运单事件和 `shipment.review.reverse` 审计。
- 业务员可通过水单到账查询为本人客户新增水单和可选凭证；财务到账后仍由财务完成匹配。运单业务自审通过、水单到账或水单更新均触发同客户同币种、余额充足应收的自动匹配尝试。
- 业务员仅进入水单到账/匹配子页，不因此获得完整财务工作台权限。
