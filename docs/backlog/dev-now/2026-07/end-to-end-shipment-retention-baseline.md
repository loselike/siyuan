# 全链路运单留存与追溯闭环

## 本轮目标

- 固定样本核验从在仓包裹、录单草稿、审核、排货、交接单、出库、客服节点、问题件到签收的留痕与追溯。
- 将关联在仓包裹、运单费用和问题件的审计记录汇入单票内部流通日志；不向客户开放内部日志。

## 已发现并处理

- 旧链路用例未适配“先打印代理交接单再出库”门禁，已补打印步骤。
- 水单创建已要求使用资料库启用的结算方式，旧测试值已调整为有效的“招商银行”。
- 单票内部流通日志原先只查询运单 ID 审计，无法显示关联在仓包裹、费用项、问题件的记录；本轮已在内存与 Prisma 仓储补齐关联对象查询和生命周期阶段映射。
- 修正内存仓储包裹分组只按客户单号聚合的问题，改为客户单号与国内快递单号联合分组，避免不同包裹来源在在仓追溯中串票。
- 面单创建不再错误要求客服“双数据确认”；该确认仍在进入待离港前校验，避免待出库阶段“先贴面单、后出库”形成状态死锁。
- 固定样本已覆盖包裹来源、草稿、审核、排货、代理交接单、出库、客服节点、问题件、签收归档，以及应收/业务成本/应付/水单留存。
